lawnmo.vercel.app
Live · Two-sided marketplace

LawnMo

A marketplace connecting homeowners with local lawn care providers: search by ZIP, request a booking, approve a firm quote, and pay in-app. Providers manage bookings and receive payouts automatically.

  • Payments architecture on Stripe Connect. A payment method is validated with a SetupIntent at quote approval, then charged off-session on job completion as a destination charge, with the platform fee split at the source.
  • Role-based auth with data kept in-house. Customer, provider and admin roles live on the user record in Postgres, with no third-party identity sync and no per-user licensing cost.
  • Built to scale the team, not just the app. Schema migrations from day one, preview-environment database branching, and every architectural tradeoff documented in the repo.
  • Next.js 16
  • TypeScript
  • PostgreSQL · Neon
  • Prisma
  • Auth.js
  • Stripe Connect
  • Vercel

lueker-lab.github.io/quickclicklearn
Live · Interactive learning platform

QuickClickLearn

A learning platform that runs real code in the browser with no installs. Courses span Python, SQL, design patterns and PMP exam prep, with accounts, saved progress and completion certificates.

  • Real runtimes, zero servers. CPython compiled to WebAssembly (Pyodide) and SQLite execute learner code client-side, so compute cost stays flat no matter how many people use it.
  • AI tutoring at the edge. A Cloudflare Worker on Workers AI answers questions in the context of the current lesson, with origin-restricted CORS and no secrets in the codebase.
  • Content as data. Lessons are declarative objects with lazily loaded dependencies (e.g. pandas loads only when a lesson needs it), so new courses ship without touching the engine.
  • JavaScript
  • WebAssembly · Pyodide
  • SQLite
  • Cloudflare Workers AI
  • GitHub Pages

lueker-lab.github.io/satellite-tracker
Live · Real-time data visualization

Orbital Situation Display

A real-time operations board tracking 105 satellites, from the ISS to GPS and geostationary craft, with live telemetry, ground tracks and a computed day/night terminator.

  • Physics in the render loop. Every object is propagated with the SGP4/SDP4 orbital model on each animation frame, with time controls up to 600× speed.
  • Operator-grade telemetry. Altitude, ground speed, period, inclination, apogee/perigee and element age, plus visibility footprints and raw TLE data per object.
  • Accessible and dependency-light. One static file, no build step, keyboard navigation, light/dark themes and reduced-motion support.
  • JavaScript
  • Real-time rendering
  • satellite.js (SGP4)
  • CelesTrak data
  • GitHub Pages

Approach

How I work

01

Right-size the architecture

02

Make tradeoffs explicit

Every significant decision, from vendor choice to payment flow, is written down with what it costs and what it buys, so the team can revisit it with context.

03

Use AI as leverage, not a crutch

I use AI tooling to compress delivery timelines and to ship AI-powered product features, while owning the architecture, review and quality bar myself.
